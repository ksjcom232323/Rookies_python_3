# 🚦 지역별 교통사고 지도

공공데이터를 수집·가공하고, 전국 17개 시·도의 교통사고 현황을 지도에서 확인하는 Python 팀 프로젝트입니다.

운전면허 소지자 통계와 교통사고 통계를 지역별로 결합하여 사고 규모, 피해 인원, 면허인구 대비 사고건수 비율을 시각화합니다.

## 데이터 처리 흐름

공공데이터 수집 → Notion DB 저장 → pandas 전처리·지역별 집계 → MongoDB 저장 → Flask 조회 → 웹 지도 표시

### 활용 데이터

- 운전면허소지자 지역별 종별 현황
- 시도·시군구별 교통사고 통계

두 데이터의 지역명과 집계 기준을 맞춘 뒤 시·도 단위로 결합합니다.

## 주요 기능

- 입체적인 대한민국 지도에 17개 시·도 표시
- 지역 표시점에 마우스를 올리면 상세 정보창 표시
- 사고건수 및 사망·중상·경상·부상신고 인원 확인
- 면허인구 대비 사고건수 비율 표시
- 운전 안전 지수를 위험·보통·안전으로 구분
- 모바일 터치 및 키보드 조작 지원

## 사용 기술

| 기술                      | 역할                      |
| ----------------------- | ----------------------- |
| Python                  | 데이터 수집 및 처리             |
| Notion API              | 수집 데이터 저장·공유            |
| pandas                  | 데이터 전처리·집계·결합           |
| MongoDB / PyMongo       | 가공 데이터 저장 및 조회          |
| Flask / Jinja2          | 웹페이지 제공 및 데이터 전달        |
| HTML / CSS / JavaScript | 지도 화면, 정보창, 사용자 상호작용 구현 |

## 데이터 구조

지역별 데이터는 다음 7개 필드로 구성합니다.

| 필드                      | 설명     |
| ----------------------- | ------ |
| `region`                | 지역명    |
| `licensed_population`   | 면허인구   |
| `accident_count`        | 사고건수   |
| `death_count`           | 사망자수   |
| `serious_injury_count`  | 중상자수   |
| `minor_injury_count`    | 경상자수   |
| `reported_injury_count` | 부상신고자수 |

사고건수의 단위는 **건**, 면허인구와 피해 인원의 단위는 **명**입니다.

## 지표 계산

**면허인구 대비 사고건수 비율(%)**

`사고건수 ÷ 면허인구 × 100`

운전 안전 지수는 위험/보통/안전으로 나뉘어져 있고 위 비율을 기준으로 지역을 비교하는 프로젝트 자체 분류입니다.

이 지표는 공식 안전 등급이나 개인의 실제 사고 확률을 의미하지 않습니다.

## 실행 방법

1. 저장소를 내려받습니다.
2. `pip install -r requirements.txt`로 필요한 패키지를 설치합니다.
3. MongoDB 연결 주소, DB 이름, 컬렉션 이름을 확인합니다.
4. `python pyproject.py`로 Flask 서버를 실행합니다.
5. test_map.html과 `pyproject.py`이 연결되어있는지 확인합니다.
6. 브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.

Flask는 MongoDB 조회 결과를 Python 리스트로 전달하고, HTML에서는 Jinja2의 `tojson` 필터로 변환하여 사용합니다.

## 참고 사항

- 데모에 포함된 가상 데이터는 실제 분석 시 수집 데이터로 교체합니다.
- 지도 이미지는 시각화를 위한 디자인으로, 정밀한 행정 경계 자료와 차이가 있을 수 있습니다.
- API 키와 DB 인증정보는 저장소에 올리지 않습니다.
