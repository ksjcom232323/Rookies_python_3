# 🚦 지역별 교통사고 지도
데이터를 활용해 교통사고 위험지역을 찾아내고 순위를 지정하고, 한정된 교통안전 자원을 어디에 우선 투입할지 판단할 수 있도록 하는 프로젝트입니다.

사고건수만으로 지역별 교통사고 위험도를 판단하는 것은 적절하지 않다고 보았습니다. 

이에 지역별 인구 규모의 차이를 반영하여 **면허인구 대비 사고건수 비율**을 계산했습니다. 또한 사망자·중상자·경상자 등 피해 유형별 수치를 함께 제공하여 사고 규모뿐만 아니라 심각성까지 구체적으로 파악할 수 있도록 했습니다.

## 데이터 처리 흐름

공공데이터 수집 → Notion DB 저장 → pandas 전처리·지역별 집계 → MongoDB 저장 → Flask 조회 → 웹 지도 표시

## 주요 기능

- 사고건수 및 사망·중상·경상·부상신고 인원 확인
- 면허인구 대비 사고건수 비율 표시
- 운전 안전 지수를 위험·보통·안전으로 구분


## 사용 기술

| 기술                      | 역할                      |
| ----------------------- | ----------------------- |
| Python                  | 데이터 수집 및 처리             |
| Notion API              | 수집 데이터 저장·공유            |
| pandas                  | 데이터 전처리·집계·결합           |
| MongoDB / PyMongo       | 가공 데이터 저장 및 조회          |
| Flask / Jinja2          | 웹페이지 제공 및 데이터 전달        |
| HTML / CSS / JavaScript | 지도 화면, 정보창, 사용자 상호작용 구현 |

## 데이터 구조

지역별 데이터는 다음 7개 필드로 구성합니다.

| 필드                      | 설명     |
| ----------------------- | ------ |
| `region`                | 지역명    |
| `licensed_population`   | 면허인구   |
| `accident_count`        | 사고건수   |
| `death_count`           | 사망자수   |
| `serious_injury_count`  | 중상자수   |
| `minor_injury_count`    | 경상자수   |
| `reported_injury_count` | 부상신고자수 |

사고건수의 단위는 **건**, 면허인구와 피해 인원의 단위는 **명**입니다.

## 지표 계산

**면허인구 대비 사고건수 비율(%)**

`사고건수 ÷ 면허인구 × 100`

운전 안전 지수는 위험/보통/안전으로 나뉘어져 있고 위 비율을 기준으로 지역을 비교하는 분류입니다.

## 실행 방법

1. 저장소를 내려받습니다.
2. `pip install -r requirements.txt`로 필요한 패키지를 설치합니다.
3. .env에 NOTION_TOKEN(개인키), NOTION_PARENT_PAGE_ID(DB로사용할PAGE_ID)를 입력합니다
4. MongoDB 연결 주소, DB 이름, 컬렉션 이름을 확인합니다.
5. `python pyproject.py`로 Flask 서버를 실행합니다.
6. test_map.html과 `pyproject.py`이 연결되어있는지 확인합니다.
7. 브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.

Flask는 MongoDB 조회 결과를 Python 파일로 전달하고, HTML에서는 Jinja2의 `tojson` 필터로 변환하여 사용합니다.
